# Privacy Policy

QOTD Automation is a personal tool used only by its developer.

It uses the Gmail API solely to send scheduled quote emails (such as a
daily, weekly, or yearly quote) from the developer's own Gmail account.
It does not read, collect, store, or share anyone's personal data, and it
does not transmit data to any third party.
